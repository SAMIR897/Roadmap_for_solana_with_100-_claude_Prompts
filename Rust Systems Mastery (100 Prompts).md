# Module 1: Rust Systems Mastery (100 Prompts)

## 1.1 The Harvard "Basics" (1-25)

1. "Professor, imagine I'm 5 years old. Why do computers use binary (0s and 1s)? Use the light bulb analogy."
2. "What is a 'variable'? If I say `let x = 5`, why can't I change it later? Explain the default of immutability."
3. "Show me a code snippet where I try to add an integer to a float. Explain why Rust refuses to 'guess' my intent."
4. "What is the 'Stack'? Use the analogy of a stack of plates in a cafeteria."
5. "What is the 'Heap'? Use the analogy of a messy warehouse with a map."
6. "Write a function that calculates the area of a circle. Explain why the return value doesn't need a `return` keyword."
7. "Explain the `if` statement. How is it like a fork in the road?"
8. "Create a loop that runs until I type the word 'exit'. Teach me about the `break` keyword."
9. "What is a `for` loop? How is it different from a `while` loop? Use the 'counting sheep' metaphor."
10. "Teach me about 'Shadowing'. If I have `let x = 5; let x = x + 1;`, what happened to the first `x`?"
11. "What are 'Scalar' types vs 'Compound' types?"
12. "Explain the `Char` type. Why is it 4 bytes instead of 1?"
13. "Build a 'Bouncer' logic that checks if a user is over 18. Use an `if/else` block."
14. "Explain 'Scope'. Why does a variable disappear when it reaches a closing curly brace `}`?"
15. "What is a 'Tuple'? How is it like a multi-flavored ice cream cone?"
16. "Explain 'Array' vs 'Vector'. Why would I choose one over the other for a list of token prices?"
17. "What is a 'String Slice' (`&str`)? How is it a window into a `String`?"
18. "Explain the `println!` macro. Why is there an exclamation mark? Is it a function or something else?"
19. "What are 'Boolean' values? How do they act like the logic of a circuit?"
20. "Teach me about integer overflow. What happens if I try to add 1 to a `u8` that is already 255?"
21. "Explain the `as` keyword for type casting. Why is it dangerous but necessary?"
22. "What is a 'Function Signature'? Why does Rust force me to label my inputs and outputs?"
23. "Explain the 'Unit Type' `()`. Why does a function that 'returns nothing' actually return this?"
24. "Write a function that swaps two numbers. Explain why I need to use the `mut` keyword."
25. "Give me a 'Broken Code' challenge: 5 lines of code with a simple syntax error. I must fix it."
